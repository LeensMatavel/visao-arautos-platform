# Visão Arautos: Spiritual Formation

Build a modern interactive web platform called “Visão Arautos”.



STACK:

- React

- Next.js

- TailwindCSS

- Framer Motion

- Firebase or Supabase authentication

- Responsive mobile-first design

- Dark elegant theme



IDENTITY:

Visão Arautos is a Christian movement focused on:

- Biblical formation

- Spiritual awakening

- Discipleship

- Missions

- Evangelism

- Pentecostal spirituality with biblical balance



The platform must feel:

- Spiritual

- Elegant

- Cinematic

- Modern

- Deep

- Mission-driven



Avoid:

- Corporate startup look

- Generic church website

- Tech company aesthetics

- Excessive futuristic design



COLORS:

- Metallic gold

- Deep navy blue

- Black

- White



MAIN FEATURES:



1. Landing Page

- Hero section

- Mission statement

- Vision Arautos presentation

- Ministry fronts section

- School Arautos section

- Call to action

- Footer



2. Authentication

- Login page

- Registration page

- User profile system

- Persistent sessions



3. Dashboard

After login users enter the Arautos Dashboard.



Dashboard sections:

- My Courses

- Progress tracking

- Notifications

- Community updates

- Recommended studies

- Events



4. Escola Arautos

Create a complete learning platform structure.



The school must support:

- Modules

- Courses

- Lessons

- Video support

- PDF materials

- Progress system

- Categories

- Student dashboard

- Completion tracking

Create admin-ready architecture for:

7. UI/UX

Generate a complete interactive JSX application structure with reusable components and scalable architecture.



Focus on:
